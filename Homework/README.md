A 2D Unity game developed as Homework for the “Game Development with Unity” course at the Faculty of Mathematics and Informatics, Sofia University.

---

## 🎮 Description

This project is a demo game featuring:

- **Player movement**  
  Basic 2D platformer walking and jumping  
  ![Player movement](./Description%20media/movement.gif)

- **Enemy AI**  
  Patrol, detect, chase  
  ![Enemy AI](./Description%20media/enemy.gif)

- **Interactive environment**  
  Moving platforms  
  ![Moving platforms](./Description%20media/moving_platforms.gif)  
  Dropping platforms  
  ![Dropping platforms](./Description%20media/dropping_platform.gif)  
  Trampoline  
  ![Trampoline](./Description%20media/trampoline.gif)  
  Power-ups  
  ![Power-ups](./Description%20media/power_up.gif)

- **Intro level**  
  Simple map with every feature in the game, must collect all 5 keys  
  ![Intro level](./Description%20media/intro_level_map.png)  
  ![Key](./Description%20media/key.png)

- **Procedurally generated levels**  
  5 difficulty levels and always different generated maps
  ![Procedurally generated levels menu](./Description%20media/pg_menu.png)  
  ![Random levels](./Description%20media/random_levels.gif)

- **Multiplayer support**  
  Pseudo-multiplayer working on local network, respawn, name tags  
  ![Multiplayer](./Description%20media/multiplayer.gif)

- **Main menu & level selection**  
  ![Main menu](./Description%20media/main_menu.png)

Built with Unity (2021.x) and leverages:
- **Unity’s Animator** for character/enemy animations  
- **Netcode for GameObjects** for peer-to-peer gameplay  
- **Audio Manager** for centralized sound effects & music
