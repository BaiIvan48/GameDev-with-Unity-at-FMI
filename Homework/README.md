A 2D Unity game developed as Homework for the “Game Development with Unity” course at the Faculty of Mathematics and Informatics, Sofia University.

---

## 🎮 Description

This project is a demo game featuring:
- **Player movement** (walking, jumping, crouching)  
- **Enemy AI** (patrol, detect, chase, attack)  
- **Interactive environment** (dropping platforms, pickups)  
- **Multiplayer support** (lobby, respawn, name tags)  
- **Main menu & level selection**  

Built with Unity (2021.x or newer) and leverages:
- **Unity’s Animator** for character/enemy animations  
- **Netcode for GameObjects** (or similar) for peer‑to‑peer gameplay  
- **ScriptableObjects** for configuration (e.g. stats, segments)  
- **Cinemachine** & **Post‑Processing** (optional) for camera control  
- **Audio Manager** for centralized sound effects & music
